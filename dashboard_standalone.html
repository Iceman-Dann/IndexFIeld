Frequently Asked Questions

What file types are supported?

IndexField supports PDF files up to 100MB. The system automatically extracts text, tables, and diagrams for AI processing.

How does the Skeleton Index work?

Our proprietary Skeleton Extraction system analyzes document structure, cross-references sections, and builds a semantic index for precise retrieval.

Is my data secure?

Yes. All data is encrypted at rest (AES-256) and in transit (TLS 1.3). On-prem deployments keep data within your network.

Can I integrate with my CMMS?

Yes. IndexField supports integrations with SAP PM, IBM Maximo, and other maintenance systems via API or webhook.

Manuals Guide

How to upload, manage, and organize your technical documentation

Upload Best Practices

  • Use original PDFs (not scanned images) for best text extraction
  • Maximum file size: 100MB per manual
  • Supported: PDFs with embedded text (not image-only)
  • Split large multi-equipment manuals into separate files

Troubleshooting

Common issues and quick fixes

Manual upload failed

Problem: PDF won't upload or process

Solutions:

  • Check file size (max 100MB)
  • Ensure PDF has embedded text (not scanned images)
  • Try reducing PDF quality if too large
  • Check System Status for maintenance
AI can't find my manual

Problem: Queries return "No relevant context found"

Solutions:

  • Verify manual status shows "Indexed" not "Processing"
  • Wait 60 seconds after upload for processing
  • Check if query uses terms from the manual
  • Try re-uploading the PDF
Slow response times

Problem: AI responses taking longer than 10 seconds

Solutions:

  • Check System Status for LLM connectivity
  • Switch to Ollama on-prem for faster local queries
  • Reduce query complexity (shorter, more specific)
  • Check network connection
Login or access issues

Problem: Can't access dashboard or features

Solutions:

  • Clear browser cache and reload
  • Verify user role has required permissions
  • Check if Enterprise license is active
  • Contact support with error message
